- I，2025-03-12：PM 做多 open_probe 4 手，PnL -2800。新闻弱多，技术和基本面 flat/弱，触发均未成立。

## 4. 辅助诊断

### 4.1 资金部署质量

当前样本不是资金参数过大导致的单纯仓位问题，而是资金部署资格问题。`exploration_probe` 的 PnL 为 -19740，且没有 `real_budget_entry` 样本承担主要资金部署。

因此，本阶段不应先调小仓位参数。应继续观察：候选质量、真实部署资格、rank 是否有效识别正期望，以及弱观察候选是否持续进入真实资金部署。

### 4.2 退出/再验证

`new_position_loss_revalidation_failed` 出现 14 次，PnL -28925，是当前最重的 reason code 亏损项。

这不代表退出机制本身一定错误。它更像是前期弱探针亏损后的确认和收尾：先由弱 open_probe 建仓亏损，再由退出/再验证记录损失。因此后续复查时要把 open_probe 入场质量和退出损失连成一个 episode 看，不能只看 exit 当天。

## 5. 当前结论

当前亏损的核心不是会计、Trader、PG 或非策略链路问题，而是策略预测与部署质量问题：

- rank 当前没有识别真实正期望；
- 弱证据、未触发、观察类候选进入真实 open_probe；
- P/M/I/ZN 的方向和触发质量偏弱；
- pullback / vwap_pullback_support 触发在短样本中负期望明显；
- 强信号放大样本几乎没有出现，系统主要在探索探针层承担收益风险。

## 6. 为什么现在不立即修改

当前只有 9 个交易日，样本太短。BU 和 EB 的 open_probe 有明显正贡献，说明不能把所有 probe 一刀切压掉。现在直接改参数或降低仓位，会把策略问题和资金利用率问题混在一起。

本阶段应继续回测，收集至少 30 个交易日，再用同一套口径复查。若每日 gate 出现 hard fail，先处理非策略问题；若只是亏损或诊断项变差，继续归入策略层观察。

## 7. 继续回测观察指标

继续回测时固定观察：

- rank=1、rank=2、rank=3 的分层 PnL 是否持续低于中低 rank；
- open_probe 的胜负比、平均盈亏、品种分布；
