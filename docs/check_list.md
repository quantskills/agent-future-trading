# AgentQuant 回测后待验收清单

只记录代码已经实现、仍等待真实回测事实验收的项目。代码测试及只读重放不代替真实回测验收；代码没有实现的功能和代码不承诺的策略效果不得写入本清单。

当前证据基线：2025-07-01 至 2025-07-18，共 14 个已完成交易日、210 条策略建议、42 条盘中决策、25 笔成交、14 条日结记录和 5 个完整 `trade_episode_memory`。最新四项修改完成于该证据基线之后，相关项目必须使用修改后空库产生的新回测记录验收。
