# AgentQuant 回测后检查清单

用于每轮最新回测结束后的逐日、逐品种、逐笔检查，确认系统不存在非策略 Bug，再评价策略表现。

## 系统与交易链

- [ ] Phase1—Phase4及Researcher逐日完整完成，无异常中断、静默降级或残留脏数据。
- [ ] AEC → SCC → PM → Auditor → Trader → Accountant → Reviewer → Researcher链路完整，字段来源和角色权限一致。
- [ ] FAC动作、目标手数、实际成交、持仓、结算、手续费、保证金与账户权益相互一致。
- [ ] 入场触发、入场作废、持仓失效、ATR止损和持有期限均被正确生产、传递和消费。
- [ ] 每品种每日最多一个策略动作；换约和forced-risk保持独立来源，不污染策略交易语义。

## PM、rank与资金

- [ ] Step4正确确定生命周期、candidate quality、probe/real/scale层级和计划比例，后续没有二次覆盖。
- [ ] 只有新增风险参与rank；rank顺序与预算消费顺序一致，非排名动作没有伪rank。
- [ ] 学习和当日证据均真实影响rank；real/scale能够由合格学习升级，并按对应层级获得更高资金比例。
- [ ] 实际保证金利用率、目标手数和20%硬门控运行正常，不存在单位混用、重复计分或无故压缩仓位。

## 学习闭环

- [ ] 每个完整持仓周期从首次开仓至最终归零只形成一个episode；分批平仓不拆成多笔策略样本。
- [ ] 换约延续原策略血缘和episode，但不单独生成策略学习。
- [ ] episode的setup、trigger和来源继承原开仓FAC，不被新闻、基本面或后续状态改写。
- [ ] 完整episode按真实净收益形成canonical action-value/profile；未完成周期、日收益碎片和非正式先验不冒充正式学习。
- [ ] 学习按open/add、hold、reduce/exit、execution生命周期正确路由；setup、trigger、方向和作用域匹配。
- [ ] T日学习只在T+1及以后生效；无匹配学习时仍能由当日证据正常冷启动。
- [ ] PM实际消费的学习能够改变候选质量、层级、rank、资金比例或生命周期，并在最终FAC记录真实影响。
- [ ] 正向学习能够把后续合格交易从probe升级至real/scale并放大仓位；负向学习能够降低质量、层级或改变入场/退出处理。
- [ ] 最终成交与结算结果准确回填到FAC实际消费的学习ID，形成可追溯反馈闭环。

## 回测结果评价

- [ ] 区分系统Bug与策略亏损：先确认系统链干净，再统计收益、胜率、profit factor、回撤和资金利用率。
- [ ] 按rank、资金层级、setup、trigger、持有期和退出原因比较完整episode表现，确认高投资价值排序具有实际区分度。
- [ ] 检查LLM调用是否按三个分析师和Researcher既定职责完成，Reviewer及确定性决策链未调用LLM。
- [ ] 样本不足时继续延长回测，不根据少量交易直接调整rank权重、止损倍数或仓位参数。
